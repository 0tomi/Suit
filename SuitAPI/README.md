Esta API esta desarrollada utilizando Laravel para gestionar consultas. 
La idea principal de este programa es que sea instalado en la computadora central encargada de manejar las peticiones de las computadoras clientes que requieran utilizar el software. 
Estos equipos que cuenten con el cliente de Suit requeriran de la computadora central haciendo de servidor para poder acceder a los datos que necesita el cliente para trabajar.
